# CSS Learning Journey & Mini-Projects 

Welcome to my CSS learning repository! This workspace contains all my experimentation files, learning notes, and mini-projects as I dived into the world of cascading style sheets.

## My CSS Journey

I started my deep dive into core CSS during the last few months of **2025**, building a strong foundation in modern web styling. By the start of **2026**, I challenged myself to put these skills to the test by building a Netflix Landing Page clone. 

However, as my study schedule grew more demanding with other academic commitments and project deadlines, the Netflix clone remains a work-in-progress (currently half-built and unresponsive). I made a strategic decision to pivot my frontend learning towards **Tailwind CSS**, as a utility-first framework aligns better with the requirements and speed of the full-stack web development projects I am currently focusing on.

## 📚 Topics & Concepts Covered

This repository serves as my personal archive of CSS concepts, documented step-by-step in the numbered files:

* **Fundamentals:** CSS Box Model, Specificity & Cascade, Sizing Units
* **Layouts:** Display Property, Clear & Float, Position Property
* **Modern Layouts:** Ultimate Flexbox, CSS Grid (Multiple experiments)
* **Design & Typography:** Fonts & Texts, Shadows & Outlines, Styling Lists
* **Advanced Styling:** Overflow handling, CSS Variables, Media Queries (Responsive Design)
* **Visual Effects:** Transforms, Transitions, Animations, Object Fit & Cover, CSS Filters
